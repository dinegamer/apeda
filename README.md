# APEDA Mali

Modern, responsive website for **APEDA Mali**, an association supporting children and families affected by learning difficulties, including dyslexia.

## Highlights

- Presentation of APEDA's mission, programs and impact
- Dedicated dyslexia-awareness content
- Activities, projects, budget and partner sections
- Testimonials and calls to action
- Responsive French-language interface
- Accessible component-based architecture

## Tech stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Radix UI
- Recharts
- Zod

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
